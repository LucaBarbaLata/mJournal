# Changelog

What changes in each version of mJournal, newest first.

When a version is released, its section here becomes the release notes on GitHub, and mJournal shows them in
*What’s new* when it says that version is out. Write for the people who use mJournal: what they’ll notice, in a few
short lines. Headings, lists, **bold**, *italics* and `code` show in the app; links show only as their text, and images
don’t show at all.

Before releasing, rename *Unreleased* to the new version number (for example `## 1.2.2`).

## Unreleased

- **See what’s new before you update.** When mJournal says a newer version is out, click *See what’s new* in the
  note in the sidebar (or *What’s new* in *Settings → Updates*) to read what changed since your version. You can
  update right from there.
